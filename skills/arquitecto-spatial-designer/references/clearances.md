# Arquitecto Clearances

Use these as planning minimums for compact hospitality layouts in Arquitecto.

| Condition | Minimum | Notes |
|---|---|---|
| Primary circulation path | 0.90 m | Prefer 1.00-1.20 m when space allows |
| Secondary side access | 0.60 m | Use only in compact zones |
| Chair pull-out behind dining seat | 0.75 m | Absolute planning minimum for active use |
| Table edge to wall/planting | 0.60 m | 0.75 m preferred |
| Fire pit edge to movable seating | 0.90 m | Avoid crowding heat source |
| Grill edge to planting | 0.60 m | More if user expects active cooking |
| Grill working side clear zone | 0.90 m | Keep free of chairs and decor |
| TV to primary seating | 1.80-3.20 m | Compact outdoor social viewing range |
| Planter as corner softener | 0.15-0.30 m from boundary | Keep out of main circulation |

Rules:

- In spaces smaller than 25 m2, protect the primary circulation path before decorative symmetry.
- If all requested objects do not fit with these minimums, reduce object size or simplify the composition instead of forcing clutter.
- Fire and grill are separate heat moments; avoid stacking them into one congested corner unless the user explicitly wants that tradeoff.
