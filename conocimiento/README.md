# Conocimiento central — Hacienda Solano

Este directorio concentra el conocimiento que la skill de diseño debe consultar
antes de preguntar o producir piezas.

## Archivos clave para el diseñador

- `conocimiento-del-negocio.md` — servicios, planes, precios, políticas, contacto, claims y copy existente.
- `Paisajismo.md` — contexto espacial, atmósfera vegetal, restricciones del predio y criterios visuales del paisaje.
- `brand/brand-identity.md` — identidad de marca, voz, tipografía, color, espaciado y reglas visuales base.
- `brand/structural-tokens.md` — decisiones estructurales del sistema visual: radius, sombras, bordes, spacing, botones, overlays y contenedores.
- `brand/organic-art-direction.md` — reglas de dirección de arte para la subfamilia orgánica y sus límites de uso.

## Regla de uso

La skill debe leer primero estos archivos y solo preguntar al usuario aquello que
no pueda resolverse desde aquí: objetivo de la pieza, prioridad estratégica,
modo de producción, o preferencias específicas para la ejecución.
