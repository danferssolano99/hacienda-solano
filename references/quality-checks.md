# Control de calidad — checklist

Ejecutá esta lista antes de considerar terminado cualquier gráfico.

## 1. Marca
- [ ] Logo visible y en la posición correcta según formato.
- [ ] Logo tiene margen de seguridad (≥5% del ancho).
- [ ] Colores provienen de `brand-tokens.css`, no inventados.
- [ ] Sin negro puro (#000) ni blanco puro fuera del token `--color-white`.
- [ ] Modo claro/oscuro testeado. El diseño funciona en ambos.

## 2. Tipografía
- [ ] Fraunces para títulos, Manrope para cuerpo.
- [ ] Máximo 2 familias tipográficas en uso.
- [ ] Título principal ≤ 2 líneas.
- [ ] Leading correcto: 1.1 para títulos, 1.5 para cuerpo.
- [ ] Sin texto justificado.
- [ ] Sin tracking negativo excesivo (< -0.05em).

## 3. Composición
- [ ] Elementos alineados a tercios o centro, no al azar.
- [ ] Espacio negativo suficiente. El diseño "respira".
- [ ] Máximo 3 bloques de texto distintos.
- [ ] Overlay legible sobre fotos claras (≥20% Deep Green).
- [ ] CTA visible y con contraste suficiente.

## 4. Contenido
- [ ] Copy revisado, sin errores de ortografía.
- [ ] Fecha, hora y lugar correctos.
- [ ] Información de contacto presente y correcta.
- [ ] Las fotos son de eventos reales de la hacienda (no stock genérico).

## 5. Técnico
- [ ] Resolución correcta según el formato destino.
- [ ] Safe zones respetadas (stories: 250px top/bottom. Posts: 80px top).
- [ ] Contraste de color cumple WCAG AA como mínimo.
- [ ] Archivo exportado en formato correcto (PNG para texto, JPEG para foto, sRGB para digital).
- [ ] Los paths de assets referencian archivos locales, no URLs externas.

## 6. Fotografía
- [ ] El activo es público → usa foto real de Hacienda Solano. Sin excepción.
- [ ] Si es moodboard/concepto interno con imagen sintética → está etiquetado explícitamente.
- [ ] Las fotos provienen de `assets/photos/`. Sin stock genérico.
- [ ] Iluminación natural, tonos cálidos. Sin filtros agresivos ni HDR.

## 7. Revisión perceptual
- [ ] El mensaje principal se entiende en tres segundos.
- [ ] Existe un único punto focal dominante.
- [ ] La pieza funciona vista como miniatura.
- [ ] El objetivo es evidente: vender, informar o construir marca.
- [ ] Comercial: el beneficio y el CTA se distinguen sin esfuerzo.
- [ ] Editorial: la atmósfera y la fotografía tienen prioridad sobre el CTA.
- [ ] Cada elemento presente tiene una función; no hay decoración gratuita.
- [ ] La pieza no parece una variación automática de otra composición.
